# 稿件匿名互评

Flask + SQLite + 原生 JavaScript 实现的稿件匿名互评网页，无需注册。

## 启动（单条命令）

```bash
docker compose up --build
```

访问地址：**http://localhost:8000**

依赖安装随镜像构建完成，建库建表随容器启动自动完成（幂等）。SQLite 数据保存在命名卷 `review_data`（容器内 `/data/app.db`），重启后数据与链接均保留。

## 使用流程

1. 打开首页，录入 3～8 人的姓名与纯文本稿件，生成私密链接。
2. 主持人保存**主持链接**（`/h/<随机串>`），把各自的**个人链接**（`/p/<随机串>`）分发给对应的人。链接随机生成、无法找回，请妥善保存。
3. 每位参与者在自己的页面：修改自己的稿件、阅读分配到的稿件（按录入顺序循环：每人评下一人，末位评首位）、提交评审意见。
4. 主持台实时显示待交人员；当每篇当前稿件都有有效意见后，主持人点击"全部公布"一次性公布。
5. 公布后，各参与者在自己的页面看到收到的匿名意见，稿件与意见均不可再改。

## 规则与实现要点

- **匿名性**：参与页及其接口响应不包含他人姓名字段与任何私密链接；公布前作者无法读取收到的意见；公布后的意见也不含评审人信息。
- **版本绑定**：每次改稿使稿件版本号 +1，并立即使针对该稿的已交意见失效（其他人的意见不受影响）。提交意见必须绑定所读稿件的版本号，版本不符（过期提交）会被拒绝，且不会覆盖已有的有效意见。
- **公布门槛**：仅当每篇当前版本的稿件都存在有效意见时才允许公布；公布为一次性操作。
- **并发与原子性**：所有写操作（改稿、提交、公布）都在 `BEGIN IMMEDIATE` 事务内"先检查、后变更"，任一规则不满足即整体回滚，拒绝的操作不留下部分变更；SQLite 开启 WAL 与 busy_timeout 以支持并发请求。
- **参与页读取语义（同一快照）**：`GET /api/p/<token>` 的全部读取放在**单个只读事务**中。SQLite WAL 模式下，只读事务的第一次读取即确定一个数据库快照，响应里的本人稿件（正文/版本）、分配稿件、我的意见、公布标志、收到的意见全部来自该快照。因此：
  - 读取进行到一半时，另一个连接完成"改稿 → 提交新版意见 → 公布"不会再拼出"已公布 + 旧版本稿件 + `received: null`"这类互相矛盾的响应（该矛盾响应正是参与页偶尔在公布后显示"（无）"的根因）；
  - 读连接可能返回**稍旧但完全自洽的公布前状态**（`published: false`，此时 `received` 按匿名规则为 `null`，属正常），下一次轮询即得到公布后快照；
  - 只读事务在 WAL 下不持任何锁，读取暂停期间另一连接仍可立即完成合法写入；
  - 已公布的快照中，公布门槛保证每篇当前稿件都有针对当前版本的有效意见，故 `published: true` 时 `received` 必为该快照中本人当前稿件的有效意见，不会为空；
  - 无论成功、链接无效（404）还是读取异常（500），只读事务都会以 `commit`/`rollback` 结束并释放连接。
- **持久化**：全部数据存于 SQLite 文件，重启后保留。

## 本地开发（不用 Docker）

```bash
pip install -r requirements.txt
python app.py
```

访问 http://localhost:8000 。数据默认写入 `./data/app.db`，可用环境变量 `DB_PATH`、`PORT` 覆盖。

## 自测（可控交错）

读取快照一致性由 `tests/test_snapshot.py` 覆盖（仅依赖标准库 + Flask，自动使用独立临时库，不影响开发数据）：

```bash
python3 tests/test_snapshot.py
```

其中 `test_interleaved...` 用线程事件把一次参与页读取挂起在"读到本人旧稿之后、读取公布状态之前"，再由另一连接依次完成**改稿 → 按新版本提交意见 → 公布**，随后放行读连接，并断言整份响应属于同一快照（只能是完整的公布前状态或完整的公布后状态，已公布时 `received` 必非空）。另外还覆盖了被分配稿件在读取期间被改的交错、多线程改稿/提交/读取压力、匿名隔离、404、读取异常 500 后事务结束与连接释放。

## 接口概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 创建会话，返回主持链接与各人个人链接 |
| GET | `/api/h/<host_token>` | 主持台状态（含待交人员、个人链接） |
| POST | `/api/h/<host_token>/publish` | 一次性公布（不满足条件则 409 拒绝） |
| GET | `/api/p/<token>` | 参与页状态（匿名：无他人姓名/链接） |
| PUT | `/api/p/<token>/manuscript` | 改稿（版本 +1，使针对它的已交意见失效） |
| POST | `/api/p/<token>/review` | 提交意见（绑定所读稿件版本，过期 409 拒绝） |
